# v5: Règles Fondamentales d'Assistance au Code

Directives d'exécution pour maximiser la productivité, la sécurité et la précision technique.

## 0. Principes Communs
- **Langue & Style** : Suivre la langue de l'utilisateur (défaut : français). Réponses concises, conclusions et diffs en premier, pas de préambule verbeux.
- **Politique d'Achèvement** : Mener la tâche jusqu'au bout sans arrêt prématuré.
- **Règle de Non-Régression** : Bannir le type `any` ou la dégradation volontaire de types pour masquer des erreurs. Résoudre les erreurs de lint/type sur-le-champ.

## 1. Classification des Tâches & Flux d'Exécution
- 🟢 **Tâche Légère (Correctifs ciblés, investigations simples)** :
  - Résumé en une ligne, lecture ciblée des fichiers pertinents, correction immédiate via `edit_file`, rapport en 1-2 phrases sans template lourd.
- 🟡 **Tâche Standard (Nouvelles fonctions, refactorings modérés)** :
  - Liste de 3 à 7 sous-tâches, modifications incrémentales, vérification des tests/lints, résumé concis des fichiers modifiés et impacts.
- 🔴 **Tâche Critique (Architecture, sécurité, suppression de données, coûts)** :
  - Planification préalable (`/plan`), évaluation des risques et procédure de rollback. Validation explicite de l'utilisateur avant toute mutation.

## 2. Politique d'Usage des Outils & Performance
- **Édition Précise** : Utiliser impérativement `edit_file` pour toute modification de code afin d'optimiser le contexte de tokens.
- **Données JSON Volumineuses** : Interdiction absolue de charger de gros JSON (>1000 lignes) avec `read_file` ou `json.load()`. Utiliser `json_query` ou le streaming (`ijson`).
- **Memory Bank (`fast-filesystem`)** :
  - Lecture sélective chirurgicale via `fast_read_file` avec chemin absolu `/home/kidpixel/workflow_mediapipe/memory-bank/...`.
  - Ne jamais charger l'ensemble du dossier en un seul bloc.
  - Synchronisation en fin de tâche via `edit_file` sur `progress.md` et `activeContext.md`.
- **Verrou de Complexité** : Dès qu'une demande implique une refonte architecturale majeure ou un nouveau sous-système, exiger l'exécution préalable du workflow `enhance_complex`.
- **Outils Autorisés** : `shrimp-task-manager`, `sequentialthinking_tools`, `edit_file`, `fast_read_multiple_files`, `json-query`.
