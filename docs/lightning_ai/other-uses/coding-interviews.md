# Coding interviews[](#coding-interviews)

If you interview at Lightning, you'll notice that we use Studios during coding interviews. If you're interviewing for an ML role, this allows us to test concepts that might require GPUs, such as optimizing models, etc.

We highly recommend using Lightning to run coding interviews \(in general\), but especially for ML engineers.

https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/Docs\_Studios\_MP4/Docs\_Studios\_Collaboration\_MouseMovingAround.mp4

# Advantages[](#advantages)

## Test real-world uses[](#test-real-world-uses)

Studios let employers test candidate's ability to use real data at scale, debug GPU systems and more. Our experience hiring AI engineers shows that synthetic coding tasks don't work super well... instead real world tasks with the real hardware yields better candidate quality.

https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/Docs\_Studios\_MP4/Docs\_DevelopmentWorkflow\_Step2Iterate\_GPUMetrics.mp4

## Run take-home tasks[](#run-take-home-tasks)

Candidates can publish take-home tasks as Studios. This allows the candidate to both build a portfolio and for hiring managers to replicate exactly the code and environment the interviewee set up. This gives hiring managers more signal in terms of real-world systems engineering.

https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/Docs\_Studios\_MP4/Docs\_Studios\_Publishing\_DuplicateStudio.mp4
