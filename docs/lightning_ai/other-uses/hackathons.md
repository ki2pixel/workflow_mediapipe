# Hackathons[](#hackathons)


Select an Image

Use Lightning to organize hackathons to enable teams to work on ML projects together, on the cloud, with a set budget of cloud credits. Hackathon participants can publish their ML projects for anyone to run, or easily turn that into a viable business. This guide describes how to organize a hackathon with Lightning.

# Set up a hackathon[](#set-up-a-hackathon)

## Create an organization[](#create-an-organization)

First, create an organization with the hackathon name.

https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/Docs\_Studios\_MP4/TeamManagement\_OtherUses\_Hackathons\_CreateOrg2.mp4

Create an organization for your hackathon.

Then, invite participants to the organization.

https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/Docs\_Studios\_MP4/TeamManagement\_OtherUses\_Hackathons\_InviteParticipants.mp4

Invite members to your hackathon organization.

## Create a teamspace per team[](#create-a-teamspace-per-team)

Within the organization, create a teamspace per project or team. A teamspace groups studios under a single shared filesystem and grants access to those resources only to those team members.

https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/Docs\_Studios\_MP4/TeamManagement\_OtherUses\_Hackathons\_CreateATeamspacePerTeam2.mp4

Create a teamspace per project / team.

Once the teamspace is created, assign the teamspace the following:

  - credits

  - access to the datasets they need

  - access to specialized compute resources \(as needed\)


https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/Docs\_Studios\_MP4/TeamManagement\_OtherUses\_Hackathons\_CreateATeamspacePerTeam\_CreditsDataCloud2.mp4

Add credits, copy templates with datasets included, and connect your cloud.

## Publish seed templates[](#publish-seed-templates)

For teams to start building, we recommend you publish a few starter templates internally that are only visible to those organization members.

https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/Docs\_Studios\_MP4/TeamManagement\_OtherUses\_Hackathons\_PublishSeedTemplates1-2.mp4

Publish starter Studios to your organization's internal Studio templates gallery.

Organization members can duplicate and start from those templates.

https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/Docs\_Studios\_MP4/TeamManagement\_OtherUses\_Hackathons\_PublishSeedTemplates2-2.mp4

Members can duplicate from templates to jumpstart their work.

## One Studio per task[](#one-studio-per-task)

Within a teamspace, we recommend you structure each part of a pipeline or task as its own Studio. For example, create one Studio that trains a model and create a second Studio that deploys the model.

## Publish the finished projects[](#publish-the-finished-projects)

Once the hackathon is done, teams can keep their Studios private or share them with the community for others to duplicate and run.

https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/Docs\_Studios\_MP4/TeamManagement\_OtherUses\_Hackathons\_PublishtheFinishedProjects2.mp4

Publish finished projects to the community.

# Advantages[](#advantages)

Running hackathons on Lightning offers many advantages.

## Set a budget[](#set-a-budget)

Lightning is the only platform in the world that lets you set a budget for a team to spend on cloud compute. This allows hackathon organizers to more efficiently use cloud credits and build more meaningful projects.

https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/Docs\_Studios\_MP4/TeamManagement\_OtherUses\_Hackathons\_SetaBudget.mp4

Set a budget for your teamspace and monitor credit consumption in teamspace settings.

## Cloud GPUs with zero setup[](#cloud-gpus-with-zero-setup)

Most AI today requires cloud GPUs or access to high-performance compute resources. Hackathon participants can instantly start a Studio and get on cloud GPUs without any friction. The work they do there can extend to a real product.


With Lightning, you can access cloud GPUs with no setup.

Select an Image

## From POC to production[](#from-poc-to-production)

Studios are used to deploy and scale some of the world's largest models across universities and enterprises. Hackathon participants can quickly turn a POC they built during a hackathon into a production system without having to set up everything again. Enable your hackathon participants to build real products and businesses faster than ever.


Lightning helps transform ideas into market-ready products.

## Organize teams[](#organize-teams)

## Publish finished work[](#publish-finished-work)

Studios can be made public and published to the world immediately after the hackathon finishes. Share on Twitter, social media, and instantly get prototypes and apps into the hands of millions of users. Participants can also deploy AI apps via the platform to get initial product-market-fit and scale their products.
