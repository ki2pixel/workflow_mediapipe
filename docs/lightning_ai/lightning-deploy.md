# Lightning deploy[](#lightning-deploy)

Lightning deploy lets you deploy autoscaling, high-performance inference APIs.

There are three main ways to deploy on Lightning:

  - [Deploy a container](https://lightning.ai/docs/overview/deploy-containers)

  - [Deploy a Studio](https://lightning.ai/docs/overview/deploy-a-studio)

  - [Deploy a turn-key model](https://lightning.ai/docs/overview/turn-key-models)
