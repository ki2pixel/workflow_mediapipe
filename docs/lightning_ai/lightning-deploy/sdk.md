# SDK[](#sdk)

Lightning AI provides a powerful set of tools across the SDK, CLI, and API to help you programmatically manage resources like Studios, Jobs, and Deployments. Whether you're automating workflows or integrating Lightning into your existing stack, this section covers everything you need to interact with the platform.

## Studios[](#studios)

Studios are interactive, persistent environments for developing and debugging machine learning workflows. Use the SDK, CLI, and API to create, manage, and access Studios directly from your code, terminal, or external systems.

* *Key features: **

  - Launch and terminate Studios via CLI or Python

  - Programmatically control Studio resources

  - Integrate Studios with data workflows and training pipelines


## Jobs[](#jobs)

Jobs allow you to run code in the cloud at scale, from training models to data processing tasks. With the SDK, CLI, and API, you can create, monitor, and manage jobs seamlessly across environments.

* *Key features: **

  - Submit and configure cloud jobs

  - Track job progress, logs, and status

  - Automate job execution in pipelines


## Deployments[](#deployments)

Deployments make it easy to turn models or apps into scalable, production-ready services. The SDK, CLI, and API let you deploy, update, and control your endpoints for real-time inference or app hosting.

* *Key features: **

  - Programmatically launch and manage deployments

  - Push updates to models or app code

  - Monitor deployed services and scale resources
