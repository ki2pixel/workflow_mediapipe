# Secure communication[](#secure-communication)

Lightning deployment supports end-to-end TLS encryption, a critical feature for achieving a SOC 2 compliant production environment.

When you enable this feature, the Lightning Platform passes the necessary TLS certificate and private key to your container as the * *LIGHTNING\_CERT\_PEM * *and * *LIGHTNING\_KEY\_FILE ** environment variables.

Your application is responsible for loading these certificates to activate secure \(HTTPS\) communication.

TLSConfig: createTLSConfig(), } # Conditionally start the server with or without TLS. if server.TLSConfig != nil { # If TLSConfig is not nil, start an HTTPS server. # The certFile and keyFile arguments are empty because the certificates # are already loaded in the server's TLSConfig. log.Println("TLS configuration found.
