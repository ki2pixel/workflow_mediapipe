# S3 buckets[](#s3-buckets)

It takes <1 minute to connect an S3 bucket. Click ` Add data ` on the top right, select AWS S3 Bucket and follow the instructions.

https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/Docs\_Studios\_MP4/Docs\_Studios\_Drive\_ConnectS3Bucket.mp4

Connect S3 buckets

An S3 connection is only available to the Teamspace; this provides ability to isolate your data as needed. You can now access it from any AWS Studio in that Teamspace.

https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/Docs\_Studios\_MP4/access\_s3\_connection.mp4

Feel free to connect multiple S3 buckets. There is no size limit to how much data you can connect.

## Private buckets[](#private-buckets)

If a bucket is private, you will need to take additional steps to authorize it. Lightning will automatically prompt you with the instructions you need. In short, it asks you to add a policy to your bucket.

https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/Docs\_Studios\_MP4/Docs\_PrepData\_ConnectS3Buckets\_privateBuckets.mp4

Add a private S3 bucket
