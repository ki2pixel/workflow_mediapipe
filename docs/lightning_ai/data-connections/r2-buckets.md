# R2 buckets[](#r2-buckets)

It takes <1 minute to connect an R2 bucket. Click ` Add data ` on the top right, select R2 and follow the instructions.

https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/Docs\_Studios\_MP4/Docs\_DataConnections\_R2-Connect.mp4

Connect R2 buckets

An R2 connection is only available to the Teamspace; this is to give you the ability to isolate your data as needed. You can now access it within any studio.

https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/Docs\_Studios\_MP4/Docs\_DataConnections\_R2-Access.mp4

Access the data from within a Studio in your teamspace.

Feel free to connect multiple R2 buckets. There is no size limit to how much data you can connect.
