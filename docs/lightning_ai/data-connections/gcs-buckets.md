# GCS buckets[](#gcs-buckets)

It takes <1 minute to connect a GCS bucket. Click ` Add data ` on the top right, select Google Cloud Storage \(GCS\) and follow the instructions.

https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/Docs\_Studios\_MP4/Docs\_DataConnections\_GCSBuckets-Connect.mp4

Connect GCS buckets

A GCS connection is only available to the Teamspace; this is to give you the ability to isolate your data as needed. You can now access it within any studio.

https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/Docs\_Studios\_MP4/Docs\_DataConnections\_GCSBuckets-Access.mp4

Access your data within your teamspace.

Feel free to connect multiple GCS buckets. There is no size limit to how much data you can connect.

## Private buckets[](#private-buckets)

If a bucket is private, you will need to take additional steps to authorize it. Lightning will automatically prompt you with the instructions you need. In short, it asks you to add a policy to your bucket.

https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/Docs\_Studios\_MP4/Docs\_DataConnections\_GCSBuckets-Private.mp4

Add a private GCS bucket
