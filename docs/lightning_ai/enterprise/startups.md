# First time set up[](#first-time-set-up)

It takes <10 minutes to set up a new organization and invite all team members.

## Create an organization[](#create-an-organization)

There is no cost to create a new organization.

To create an organization, navigate to the top left of the screen and click the title on the top left. Then, click "New Organization":

https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/Docs\_Studios\_MP4/Docs\_TeamManagement\_StartanOrg2.mp4

Create an organization by clicking on the name or title at the top of the left-hand sidebar.

## Add organization admins[](#add-organization-admins)

Invite the members who will manage the organization. Organization admins have elevated permissions to manage members, cloud accounts, budgets and more.

https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/Docs\_Studios\_MP4/TeamManagement\_Organization\_AddAdmin-TopButton3.mp4

Invite members and make them admins to allow them access to additional permissions.

## Add organization members[](#add-organization-members)

Invite all colleagues to the organization as members. Each member automatically gets their own teamspace.

https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/Docs\_Studios\_MP4/TeamManagement\_Organization\_AddMember-TopButton3.mp4

Added members automatically get their own teamspace.

## Add cloud account \(optional\)[](#add-cloud-account-optional)

Your organization comes with the default, secure cloud account. Connect a private cloud account for organizations who want to use their own AWS credits or run on their private cloud infrastructure.

https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/app-2/cloud\_account.mp4

Add your AWS account.

Adding your own cloud account allows the organization to consume your own cloud credits and run on private infrastructure.

It's free to get started with Lightning organizations. Pay as you go while you prototype and get projects started. As projects mature or you need advanced functionality, unlock new features by upgrading to different tiers. Compare [advanced features here](https://lightning.ai/pricing#compare) .

https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/Docs\_Studios\_MP4/TeamManagement\_Organization\_Pricing2.mp4

# Organize work[](#organize-work)

Use these recommendations to structure work inside an organization.

## One teamspace per use case[](#one-teamspace-per-use-case)

Set up a teamspace per use case. This is normally done by organization members as new use cases come up.


Set up a teamspace per use case.

Select an Image

A teamspace isolates data access to a group of people under a business goal. Each teamspace will group Studios and data related to a use case. For example if the project is to build a fraud detection system, the teamspace will be "fraud detection" and the Studios in the teamspace will be different tasks \(train model, finetune, deploy, etc...\).

https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/TeamManagement\_Organization\_OneTeamspacePerUseCase.mp4

Create a new teamspace for each use case you have at your organization.

## One Studio per task[](#one-studio-per-task)

Organization members will create multiple studios inside a teamspace. Each Studio should be isolated to one task with a stand-alone cloud environment.


Create one studio per task.

Select an Image

All studios can access the same files in the teamspace, so you can create a dataset on one Studio and access it from a second Studio.

https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/Docs\_Studios\_MP4/TeamManagement\_Startups\_OneStepAtaTime\_AccessFilesAcrossTeamspace.mp4

Access dataset across Studios within the teamspace.

## Create Studio templates[](#create-studio-templates)

A way to share work across the organization is to publish Studios to the internal library. Organization members can duplicate these Studios into different teamspaces.

https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/Docs\_Studios\_MP4/Docs\_Studios\_DuplicateStudios\_DuplicateByPublishing2.mp4

Create studio templates for your startup to duplicate.
