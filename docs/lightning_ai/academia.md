# Lightning use by team size[](#lightning-use-by-team-size)

This section describes our recommendations of how to structure Lightning by each academic use case.

## Students[](#students)

For students a single teamspace is likely enough for most work types. However, we recommend to set up a standalone teamspace for each class so you can group homeworks, projects, etc...


Create a teamspace for each project.

Select an Image

It is also a good idea to set up a teamspace for every collaborative project \(hackathons, etc...\) where each member might be working on something different that contributes to the overall project.

Read the [in-depth guide](https://lightning.ai/docs/team-management/academia/students) for students.

## University class[](#university-class)

Lightning Studios allows professors or teachers to focus on delivering core course content instead of hours helping students set up and troubleshoot local environments.

Use Lightning for a university class to allow students to start coding with zero setup and full control. Lightning enables instructors to share homeworks and assignments as reproducible templates, manage cloud credits and control spend. Teaching assistants and students can pair code live on Studios to conduct virtual office hours or offer homework help.

Press Share to get a link for coding together with collaborators.

Read the [in-depth guide](https://lightning.ai/docs/team-management/academia/university-class) for classrooms.

## University lab[](#university-lab)

Use Lightning to organize work across a research lab. Such labs are either managed by a single principal investigator \(PI\) or multiple PIs.

Lightning allows PIs to organize research by effort, provide data isolation, manage spend, use cloud credits, provide live-coding help for researchers and more. Most cloud credit grants go unused or are inefficiently used because labs lack the right tools. These are the key problems Lightning can help with.


Lightning gives PIs a range of capabilities to enhance research.

Select an Image

Once research is complete, fully reproducible studios can be made open source which eliminates the need to "get the code ready for release" and makes research fully reproducible end to end.


Studios let you publish reproducible research without prepping code for release.

Select an Image

Read the [in-depth guide](https://lightning.ai/docs/team-management/academia/university-research-lab) for research labs.

## University-wide[](#university-wide)

Use Lightning to organize all research efforts across a university. Lightning allows administrators to provide access to cloud compute resources and private clusters to all students and researchers. It's a way to manage cost and resources at scale.
