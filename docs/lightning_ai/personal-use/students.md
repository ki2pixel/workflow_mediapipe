All users on Lightning get 1 Studio running free 24/7 and 80 GPU hours per month \(15 Lightning credits\). The free CPU Studio is enough for coding anything at any time. The Studio will be free for the first 4 hours and then switch to billed. Restart the Studio to continue coding for free.

# Organize work[](#organize-work)

This section describes our recommendations to organize work as a student. In principle, think of a teamspace like a folder and studios as files.

## A teamspace per project[](#a-teamspace-per-project)

For students a single teamspace is likely enough for most work types. However, we recommend to set up a standalone teamspace for each class so you can group homeworks, projects, etc...


Create a teamspace for each project.

It is also a good idea to set up a teamspace for every collaborative project \(hackathons, etc...\) where each member might be working on something different that contributes to the overall project.

## A Studio per task[](#a-studio-per-task)

Imagine if you could have a new laptop every time you wanted to work on something new. And if you broke that laptop, you could just throw it away. That's exactly why we recommend to set up a Studio for every project. When you want to work on that project, start the Studio and everything's already set up.

# Reduce costs[](#reduce-costs)

Lightning is very student and academic friendly. We've given all students 15 free credits per month which is enough to run 35 hours of GPUs, and a free running CPU studio. For our academic users this is more than enough to support ongoing classes and side projects.

If you need more credits, recommend to your instructors to create a lightning organization for the class and add credits there. Most universities have cloud credits and budgets they can use for classes through Lightning.

Read our [academic guide here](https://lightning.ai/docs/team-management/academia) .

## Why only 80 free hours?[](#why-only-80-free-hours)

Do the majority of your coding, debugging, and iterating on a CPU Studio. Then, when you need to validate something, run on a cheap GPU and then scale to an expensive GPU.

This means that 1 hour on Lightning is roughly equivalent to 5 hours in other platforms. On other platforms, you will have a ton of failures and issues that will force you to waste GPU compute on non GPU tasks.


Working in Lightning is incomparably quicker and cheaper.
