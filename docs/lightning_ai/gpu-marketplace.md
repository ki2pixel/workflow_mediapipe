# Availability types[](#availability-types)

## On-demand[](#on-demand)

When you start a workload \(like a Studio or Job\) without reserving machines in advance, it runs on-demand. You pay only for the time you use.

_ * *Note * *_ : Availability for on-demand depends on supply and demand - popular GPU types may be temporarily sold out.


When starting workloads \(like a Studio here\) it will run on-demand

Select an Image

## Reserved[](#reserved)

When workloads need guaranteed capacity or will run continuously, reserve instances in advance. You’ll get dedicated resources at reduced rates.

Contact our team to reserve instances \(support@lightning.ai\)

# Cloud agnostic storage[](#cloud-agnostic-storage)

Lightning provides cloud agnostic folders that let you store data that can easily move across clouds without ingress/egress fees. This allows you to take advantage of the best available compute without worrying about where your data lives.

Create a "New Folder" and select "Lightning Storage" to create your first cloud-agnostic read/write folder on Lightning. This data will be available across any machine.
