# Plugins[](#plugins)

Just like apps on a smartphone, Lightning Studios support plugins—modular building blocks that extend your Studio with powerful AI functionality. Whether you need to run batch jobs, call an LLM, or deploy an API, plugins let you build complete AI products without duct taping disparate tools together. Studios include a growing library of official plugins, and enterprises can even develop their own.

# Work with plugins[](#work-with-plugins)

## Use a plugin[](#use-a-plugin)

Click the + button to browse available plugins. Once you find a plugin, install it.

Hover over the plugin for action shortcuts.

Some plugins can open fullscreen by double clicking on them.

Plugins are generally self-explanatory; the best thing you can do is experiment with them. Each plugin has its own documentation as well.

## Write a plugin[](#write-a-plugin)

The beauty of Studios is that if you don't like how we do a workflow \(e.g., train multi-node\), you can write your own plugin with your own logic. Writing a plugin is kind of like writing a bespoke ML platform for your particular use case.

## Private plugins[](#private-plugins)

Enterprises usually have custom internal tools that they want to integrate with Lightning. For example, internal databases, regulatory reporting tools, SEC reporting tools, etc.

Studios can integrate all these services via plugins. Please [get in touch](https://discord.gg/MWAEvnC5fU) if your organization needs this.

## Request a plugin[](#request-a-plugin)

If you have favorite tools that you'd like to see integrated with Lightning or you develop a tool you want to make available to the Lightning community, please [get in touch](https://discord.gg/MWAEvnC5fU) . Our goal is to provide integrations with the best-in-class tools the AI community loves.
