# Base Studios[](#base-studios)

Base Studios provide a way to standardize and customize the environment for launching Studios within an organization.


Base Studios

Select an Image

Base Studios provide a standardized, customizable, and secure template for launching studios, enabling users to quickly deploy consistent and compliant environments. By leveraging Base Studios, organizations can streamline studio setup, reduce administrative burden, and improve overall efficiency, allowing users to focus on high-value work and drive business results.

## Access Control[](#access-control)

Only administrators of an organization have the ability to create, update, and delete Base Studios. However, all users within an organization can launch studios from a Base Studio.

# Create base studios[](#create-base-studios)

By creating a Base Studio, administrators can establish a standardized and secure template for launching studios, ensuring consistency and compliance across the organization. This enables users to quickly deploy pre-configured environments, saving time and reducing errors, while also allowing administrators to maintain control and governance over studio configurations.


Creating a Base Studio

Select an Image

  1. Log in to the administration interface

  2. Navigate to the Base Studios section under the Control Center or the dropdown for your org.

  3. Click on the "New Base Studio" button to open the form.

  4. Fill in the configuration, including Base Studio name, machine image, coding environment, machines, and custom setup script.

  5. Create it by clicking the "New Base Studio" button in the form.

# Use a base studio[](#use-a-base-studio)

By using a Base Studio, users can quickly launch a pre-configured and secure environment, saving time and reducing errors, and focus on high-value work. Using a Base Studio also enables users to leverage a standardized and compliant setup, ensuring consistency and reliability across projects and workflows.


Launching a Studio using a Base Studio

Select an Image

* *To launch a studio from a Base Studio: **

  1. Log in to Lightning AI

  2. Click on the "New Studio" button to launch a Studio as normal

  3. All users will now see a scrollable list of cards for each Base Studio configured

  4. Select the Base Studio to use for the Studio.

  5. Set any additional settings as needed

  6. Hit "Start"

## Update base studios[](#update-base-studios)

Updating a Base Studio allows administrators to reflect changes in organizational policies, tools, or configurations, ensuring that all studios launched from the Base Studio remain up-to-date and compliant. By keeping Base Studios current, organizations can maintain a consistent and secure environment, reducing the risk of errors or security breaches.

  1. Navigate to the Base Studios section.

  2. You will be able to see all created Base Studios in the table

  3. Find the Base Studio to be updated and hover on the row.

  4. Click on the menu button that appears on the left

  5. Click the Edit button

  6. Make the necessary changes to the Base Studio configuration.

  7. Click "Update Base Studio" to save the changes.


## Delete base studios[](#delete-base-studios)

Deleting a Base Studio allows administrators to remove outdated or unused templates, streamlining the Base Studio catalog and reducing clutter. By deleting unnecessary Base Studios, organizations can improve governance and reduce the risk of users launching studios from outdated or insecure templates.

  1. Navigate to the Base Studios section.

  2. You will be able to see all created Base Studios in the table

  3. Find the Base Studio to be updated and hover on the row.

  4. Click on the menu button that appears on the left

  5. Click the Delete button

  6. A warning will pop up to confirm deletion. Fill out the requirements

  7. Click "Delete" to delete the Base Studio.


## Disable visibility[](#disable-visibility)

Changing the visibility of a Base Studio enables administrators to control who can access and use a particular template, ensuring that sensitive or restricted environments are only available to authorized users. By managing Base Studio visibility, organizations can maintain control and governance over studio configurations, reducing the risk of unauthorized access or misuse.

Instead of deleting a Base Studio permanently, you can also change if users in your Org will be able to use the Base Studio

  1. Navigate to the Base Studios section.

  2. You will be able to see all created Base Studios in the table

  3. For each Base Studio, mark the checkbox with whether or not it is enabled
