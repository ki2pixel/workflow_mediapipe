# First time set up[](#first-time-set-up)

## Create teamspace[](#create-teamspace)

Create a teamspace for your personal project.

## Add credits[](#add-credits)

Add credits to the teamspace to set a budget. Use the activity tab to monitor costs. There is a "wallet" that belongs to your user and one for each teamspace. This ensures that any credits that you receive from your subscriptions always end up in the same user wallet. From there, you can transfer them to any project you're working on in a teamspace.

## Create one Studio per project[](#create-one-studio-per-project)

Create one Studio per project or idea you are working on. Each Studio is limited to a single environment.

This allows you to have independent environments for each task or project you are working on.

## Invite collaborators[](#invite-collaborators)

If you're working on a joint project, invite your collaborators to the Teamspace. There, you'll all be able to see and build on each other's work.

https://pl-bolts-doc-images.s3.us-east-2.amazonaws.com/Docs\_Studios\_MP4/TeamManagement\_PersonalUse\_SideProjects\_AddMembers.mp4

Use the Invite button to add additional members and admin to your teamspace.

# Grow[](#grow)

As projects mature, we recommend to create an organization \(free of charge\) and move all your work there. This will allow your work and projects to scale as you continue to add more team members.
